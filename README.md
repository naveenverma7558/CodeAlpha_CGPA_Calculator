# CGPA Calculator Using C++

## About the Project
The CGPA Calculator is a C++ programming project developed as part of the CodeAlpha C++ Programming Internship.

It calculates a student's GPA using grade points and credit hours for multiple courses.

## Features
- Accepts multiple courses as input.
- Takes course name, grade point, and credit hours.
- Calculates total credit hours.
- Calculates total weighted grade points.
- Displays the calculated GPA.
- Validates grade points and credit hours.

## Formula

GPA = Total Weighted Grade Points / Total Credit Hours

Total Weighted Grade Points = Grade Point × Credit Hours

## Technologies Used
- Programming Language: C++
- IDE: Visual Studio Code
- Compiler: GCC (g++)

## How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Compile the program:

   g++ cgpa_calculator.cpp -o cgpa

4. Run the program on Windows:

   .\cgpa.exe
